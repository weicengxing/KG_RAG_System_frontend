# Game Model Asset Sources

The production-style placeholder models in this folder use CC0 KayKit assets:

- `player.glb`: KayKit Character Pack: Adventures, `Barbarian.glb`.
  Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
- `tribe_hut.glb`: KayKit Medieval Hexagon Pack, packed from `tent.gltf`.
  Source: https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0
- `cave_entrance.glb`: KayKit Medieval Hexagon Pack, packed from `building_mine_green.gltf`.
  Source: https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0
- `tribe_totem.glb`: KayKit Medieval Hexagon Pack, packed from `flag_green.gltf`.
  Source: https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0
- `campfire.glb`, `tribe_storage.glb`, `tribe_workbench.glb`, `tribe_flag.glb`: local low-poly production props generated by `frontend/scripts/generate-prop-models.mjs`.
- `resource_site.glb`, `map_memory.glb`, `world_event_remnant.glb`, `diplomacy_council.glb`, `standing_ritual.glb`: local low-poly gameplay marker props generated by `frontend/scripts/generate-prop-models.mjs`.
- `sacred_fire.glb`, `neutral_sanctuary.glb`, `collection_wall.glb`, `shared_puzzle.glb`, `trail_marker.glb`, `named_landmark.glb`, `world_riddle_site.glb`: local low-poly culture, ritual, route, naming, and puzzle marker props generated by `frontend/scripts/generate-prop-models.mjs`.
- `old_camp_echo.glb`, `cave_return_mark.glb`, `traveler_song.glb`, `mutual_aid_alert.glb`, `nomad_visitor.glb`, `trial_ground.glb`: local low-poly return, rescue, visitor, alert, song, and trial marker props generated by `frontend/scripts/generate-prop-models.mjs`.
- `natural_tree.glb`, `natural_rock.glb`, `natural_grass_tuft.glb`, `natural_flower_patch.glb`, `region_marker.glb`, `migration_site.glb`, `nomad_caravan.glb`: local low-poly nature and travel marker props generated by `frontend/scripts/generate-prop-models.mjs`.
- `player_torch.glb`, `player_stone_tool.glb`, `player_scroll_token.glb`: local low-poly player hand props generated by `frontend/scripts/generate-prop-models.mjs`.

KayKit assets are published as CC0/public domain assets by Kay Lousberg.
The older generated GLB files are kept as local fallbacks and can be replaced or removed after a fuller art pass.
